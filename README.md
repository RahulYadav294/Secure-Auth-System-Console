# Secure Authentication System (Console-Based)

## 🔹 Project Overview
This project is a console-based secure authentication system developed using Java.  
It demonstrates core backend concepts such as user registration, login authentication, password hashing, and role management following clean code and layered architecture principles.

---

## 🔹 Features
- User registration with username, password, and role
- Secure password storage using SHA-256 hashing
- Login authentication with hashed password comparison
- Role-based user identification (Admin/User)
- Console-based interactive menu
